php-baremetal sim — PHP on an emulated ESP32-S3

Write PHP 8.5, press Run and watch an emulated ESP32-S3 blink LEDs, read buttons and talk I²C. Nothing to install, nothing to flash.

How it works

  1. Write index.php: setup() runs once, loop() runs forever.
  2. Add packages to composer.json from the php-baremetal registry: extensions, drivers, PHP extensions.
  3. Press Run: the server builds the php-baremetal firmware with phpbm and the emulated chip boots it.

Examples

  • Blink SOS
  • Button → LED
  • I²C clock (DS3231)
  • Button events (event-driven)
